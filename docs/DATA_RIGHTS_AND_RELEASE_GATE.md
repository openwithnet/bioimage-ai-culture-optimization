# Part III — 데이터 이용 조건 및 공개 게이트 (2026-10-21)

## 검증된 1차 자료
- Cell Tracking Challenge(CTC), https://celltrackingchallenge.net/datasets/ : 데이터는 다운로드 가능하지만, 공식 이용 조건에 따르면 **비-CTC 관련 공개 과학적 사용에 주최 측 명시적 허가가 요구**되며 데이터와 주석의 전체 또는 일부 복제·재배포가 금지된다. 출처 논문 인용도 요구된다.
- CTC 관련 학습 코드 공개가 어떤 허가 범주에 해당하는지는 **확인되지 않았다**. 공개 라이선스 Apache-2.0은 데이터 이용 허가를 대신하지 않는다.
- B01–B05의 Notebook은 CTC 자료를 읽는다. 원본 데이터는 배포에서 제외한다.
- 원본 실행 Notebook에 포함된 embedded PNG 출력은 CTC 이미지 파생물이 섞였을 가능성을 배제할 수 없어 **공개 후보에서 전체 Notebook 출력을 일괄 제거**한다. 이 과정은 소스 코드 셀과 Markdown 셀을 유지한다. 원래 실행 결과와 감사 기록은 비공개 원본 패키지에서 보존한다.
- B06–B08 Aida–Ying media/OD600 Excel 출처, 내려받기 URL, 사용 조건은 **검증되지 않음**. 공개 후보에서 원본 Excel은 제외한다. 재현 가능한 다운로드 안내는 해당 출처 확인 이후에만 작성한다.

## 공개 전 필수 조치
1. CTC 측 공개·교육 용도의 이용 조건 해당 여부 확인; 불명확하면 공개 전 권리자/운영자에 문의.
2. Aida–Ying 원본 파일의 출처, 정확한 파일명·개수, 인용, 권리·사용 조건 확인.
3. 검증된 데이터 취득과 경로 정리 후 별도 환경에서 B01–B08 단계별 재실행.
4. 생성 그림·표·노트북 실행 결과를 다시 저장소에 포함할 때, 권리와 비식별성을 별도 확인.
5. 릴리스 후보는 **공개 허가 확정이 아니라 준비 상태**이다.

참고: https://celltrackingchallenge.net/datasets/ (2026-10-21 확인)
