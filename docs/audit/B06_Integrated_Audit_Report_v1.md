## 3. 과학적 검증의 경계

1. **연결 키 정합성은 충분히 확인되었으나** 원 논문의 `K`, `r`, `K_info`, `r_info` 계산 정의 및 상태 코드 의미는 독립적으로 확정되지 않았다. 기존 K와 관측 최대값의 상관이 매우 높아도 동일 정의라는 의미는 아니다.
2. 관측된 **라운드 간 OD 차이**는 배지 조성, 기기 운영, 측정 구간의 영향과 혼재할 수 있다. 인과적 배지 효과로 해석하지 않는다.
3. 동일 Condition ID의 다수 곡선은 **독립 생물학적 반복**을 보장하지 않으며, 조건별 반복수 불균형(6~588개)이 크다.
4. 로지스틱 최적화 성공(832)은 과학적 신뢰성 검증이 아니다. **탐색적 수치 품질 통과(677)** 역시 생물학적 성장률/지연시간의 타당성이 입증된 숫자가 아니다.
5. `lag_proxy`는 기하학적 대용값이며, 국소 최대 로그 기울기는 창 길이와 측정 잡음에 민감하다. 생물학적 lag time/최대 비성장률로 직접 명명하지 않는다.
6. B06-03의 840개 표본은 조건 분산 난수 표본이지만 모집단·독립 실험의 대표성을 보장하지 않는다. 원본 `r`과의 상관이 낮아도 잘못 계산했다는 결론은 단정할 수 없다.
7. SHA256 manifest와 CSV 재읽기 검사가 Notebook 내 기록된 사실은 확인했지만 **독립한 두 번째 환경의 재현 실행**을 증명하지 않는다.

## 4. B07로 넘길 때 필요한 정식 입력 계약

- **권장 기본 단위:** `Condition ID`를 그룹으로 정의하되 라운드(`round`)와 반복 구조를 함께 유지한다. 단위는 **조건별 독립 재현성**이 아닌 조건별 반복관측임을 문서화한다.
- **특성(X):** `BW25113_Medium composition.xlsx`의 농도 열(단위 mM 표기 등)은 실제 숫자·결측·상수 특성·중복 행·스케일을 확인한 뒤 사용한다. `Label`, `Assay ID`, `Condition ID`, `Round`는 화학 조성 특성이 아니다.
- **표적(y):** 1차는 원 자료 `K`, `r`과 관측 기초 통계의 각각을 별도 분석하되, 원 `K/r`의 정의가 미확인인 상태에서 생물학적 성장률로 명명하지 않는다. 품질 코드(`K_info`, `r_info`)의 정의가 확보되면 선정/가중 규칙을 재평가한다.
- **검증 분할:** 동일 Condition ID가 학습·테스트에 동시에 들어가지 않도록 **GroupKFold / GroupShuffleSplit**을 우선 검토한다. Round 배치 효과는 별도 검사한다. 무작위 Well/Curve 분할의 누출 가능성에 주의한다.
- **기준 모델:** 단순 평균/중앙값 및 Ridge/RandomForest 등 설명 가능한 베이스라인을 먼저 구축한다. 결과가 실제 데이터 실행 검증을 통과하기 전에는 성능을 예측해 제시하지 않는다.
- **비교 범위:** 예측 가능성·일반화 가능성과 화학 조성 변경의 인과 효과는 다른 문제다. 최적 배지 검증은 후속 실험 없이 주장하지 않는다.
