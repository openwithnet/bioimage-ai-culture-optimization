## 1. 감사 범위와 결론

**판정: 기록 기반 코드 실행·핵심 수치 정합성 통과. 신규 실험 검증 및 원본 데이터 독립 재현은 미완료.**

| 단계 | 실행된 코드 셀 | 오류 출력 | Word 해설서 열람 |
|---|---:|---:|---|
| B08-00 | 7/7 | 0 | 확인 |
| B08-01 | 7/7 | 0 | 확인 |
| B08-02 | 7/7 | 0 | 확인 |
| B08-03 | 8/8 | 0 | 확인 |
| B08-04 | 7/7 | 0 | 확인 |

합계 코드 셀 **36개**, 실행 기록 **36개**, 오류 출력 **0건**. 모든 Word 해설서는 docx 패키지로 열렸고 주요 Python 및 연습문제 관련 내용이 확인되었다. Word 풀이 코드는 개별 실행 검증하지 않았다.

## 2. 단계 간 연결과 정합성

| 비교 항목 | Notebook 출력 기록에 따른 확인 |
|---|---|
| B08-00 후보군 | 1,025개 배지 조성, 44개 성분, 원본 B07과 `n_rounds` 불일치 0건 |
| B08-01 순차 선택 | 2개 목표 × 2개 전략 × 3개 시드 × 20회 = 240건 |
| B08-02 BO 추가 | 2개 목표 × 3개 전략 × 3개 시드 × 20회 = 360건 |
| B08-02 ↔ B08-01 | Random/RF_greedy 결과 재현 확인 출력 |
| B08-03 ↔ B08-01 | 12개 실행 결과 대조 성공 출력 |
| B08-04 후속 실험 | 기존 1,025개 조성에서 13개 후보 제안, 신규 원시 측정 없음 |

### 최종 최고값의 시드 3개 평균 (Notebook 출력 반영)

| 목표 | Random | RF_greedy | GP_EI |
|---|---:|---:|---:|
| `K_median` | 1.2872 | 1.3238 | 1.3325 |
| `r_median` | 1.3873 | 1.4804 | 1.4178 |

3개 시드는 **같은 원본 데이터셋의 재분할**이며 독립 실험 3회의 결과가 아니다. GP_EI는 K 평균에서, RF_greedy는 r 평균에서 앞섰으나 알고리즘의 보편적 우월성을 입증하지 않는다.

## 3. 코드·산출물·해설서 의존성

```text
B07-00 조성 수준 데이터 + B08-00 검증 후보군
          ↓
B08-01 Random / RF_greedy  → 선택 이력
          ↓
B08-02 Random / RF_greedy / GP_EI → 선택 이력 360건
          ↓
B08-03 예산·선택편향 감사
          ↓
B08-04 13개 후속 검증 후보와 프로토콜
```

실제 사용자 PC의 `results/bioculture/B08_*` 경로에 있는 CSV/JSON 산출물 및 원본 Excel은 현재 환경에 없어 디스크 파일의 해시를 직접 대조하지 못했다. Notebook에 저장된 재읽기 검사·SHA256 생성 기록만 확인했다.

## 4. 과학적 주장 감사

- **확인됨:** 공개된 과거 OD600 배양 자료에서 후보군을 형성하고, 숨긴 기존 실측값을 순차 선택 후 공개하는 오프라인 시뮬레이션을 실행하였다.
- **확인됨:** 대상 조성·시드·실험 예산에 따른 탐색적 순위 및 선택 편향 기록.
- **제한:** 목표값이 결측인 조성을 후보군에서 사전 제외하므로 전향적 실험의 실패 위험을 충분히 반영하지 못한다.
- **제한:** 배지 조성과 실험 라운드가 얽혀 있으며 B07 단계에서 다른 라운드에 대한 예측 실패가 관측되었다.
- **미검증:** 새로운 OD600 실측, 실험실 안전 검토/승인, 독립 배치 재현성, 실험적으로 입증된 최적 조성, 성분의 인과 효과.

## 5. 교재·배포 준비 판정

1. B08-00~04 Notebook과 Word 안내서 각각의 **1차 교육자료 세트는 구비**되어 있다.
2. B08-01~03의 성과 수치를 서로 대조한 기록은 일관된다.
3. **완전 재현 게이트 보류:** 원본 Excel 및 사용자 PC에 생성된 CSV/JSON을 새 환경에서 독립적으로 실행·재생성할 필요가 있다.
4. **과학 주장 게이트 보류:** B08-04의 새 실험은 설계 상태이며 검증된 신규 결과로 소개하면 안 된다.
